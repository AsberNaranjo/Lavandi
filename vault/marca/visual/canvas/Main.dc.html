Decisión 2 · Símbolo
Dejar de dibujar la inicial
Una L sirve para una librería o una aseguradora. Dos caminos para que el símbolo signifique algo.
Antes de dibujar: el azul Agua no pasa el contraste mínimo como texto ni como botón. Se corrige derivando un tono, no cambiando el color. La medición está en la siguiente lámina.
